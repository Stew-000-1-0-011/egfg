# 実験レポート（フェーズ F）：因子の低ランク分解（消去順序では表せない等式）

- 日付：2026-10-06
- データ：`results/low_rank.csv`（40 行）、ログ：`results/low_rank.log`
- 再現：`uv run python experiments/low_rank.py --out results/low_rank.csv`（3 プロセス並列で約 1 分）
- 仕様：`docs/superpowers/specs/2026-10-06-low-rank-design.md`

## 1. 何を調べたか

2 変数因子の表が低ランク（ランク r）のとき、φ(a,b) = Σ_z U(a,z)·V(z,b) という等式を e-graph に入れました（z は状態数 r の新しい変数）。これは、元の変数の消去順序だけでは表せない計算を可能にします。

表は、非負の乱数行列の積でランク r にしました。種類は鎖・星形・ランダムな木・輪・2 行の格子、K = 8（n = 8）と K = 16（n = 6）、r ∈ {1, 2, 4, K} です（r = K は分解できない場合）。

比べたもの：

- 分解なし（既定の探索、seeds+staged）
- 分解あり（同じ探索に、分解の等式を加えたもの）
- 既知の工夫による比較の相手（「known」）。次のうち最も安いもの。
  - 元のグラフの best-JT+
  - 分解できる因子をすべて分解したグラフの best-JT+
  - 木では、BP と、分解したグラフ上の BP（低ランク BP）

## 2. 結論の要約

1. **H14：「はい」。** 低ランクの表では、分解ありのコストは分解なしよりずっと小さくなりました（r = 1 で 0.007〜0.24 倍、r = 2 で 0.03〜0.64 倍）。K = 16 の輪と格子の r = 1 では 1/100 以下でした（輪で 67584 → 504）。
2. **H15：「はい」。** 40 ケースすべてで、分解ありのコストは既知の工夫の最良（known）以下でした（0.58〜1.00 倍）。
   - 分解しても得をしない場合（鎖とランダムな木で r = 4、K = 8）、e-graph は分解を使いませんでした。一方、「全部分解したグラフ」の best-JT+ は、元のグラフより悪くなっていました。
   - 輪と格子では、分解を「どの因子で使い、どの因子で使わないか」を混ぜた計算を選び、known の 0.58〜0.89 倍になりました。全部分解するか、全部分解しないかの二択では得られない計算です。
3. **例外が 1 つ**：星形（K = 8、r = 4）で、分解ありが分解なしより少し悪くなりました（1520 対 1504）。分解の等式を入れると e-graph が大きくなり、ノード上限に早く達したためです。分解なしの解も候補に入れる、などの対策が必要です。
4. **正しさ**：40 ケースすべてで、周辺分布が総当たりと一致しました。

## 4. 注意点

- **和と積でしか使えない**：分解は z についての和を使うので、最頻値や期待値の計算には使えません（使おうとするとエラーになります）。
- **表の値に依存する**：分解できるかどうかは、表の値（ランク）で決まります。フェーズ B〜E の「構造だけで決まる」探索と違い、表が変わる（たとえば時刻ごとに変わる観測の表）と使えるかどうかが変わります。
- **低ランクの表は人工的に作った**：実際のモデルで表がどれくらい低ランクかは、問題によります。近似的に低ランク（小さな特異値を捨てる）にすると、近似になります（今回は扱っていません）。
- **既知の工夫との関係**：低ランク分解そのもの（低ランク HMM など）は既知の工夫です。今回の主張は、「どの因子で分解を使うかを、ほかの工夫（消去順序、共有）と組み合わせて自動で選べる」ことです。

## 5. 次の課題

1. 分解なしの解も候補に入れて、分解ありが分解なしより悪くならないようにする。
2. 近似的な低ランク分解（誤差つき）。
3. ほかの「消去順序では表せない」等式：畳み込みと FFT、決定的な因子の分解、noisy-OR。
