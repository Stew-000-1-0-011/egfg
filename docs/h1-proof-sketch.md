# H1 の証明スケッチ：木構造では、最適な DAG 抽出のコストは BP 以下

実験（`experiments/REPORT.md`）で成り立ったことを、証明の形に整理したものです。まだ穴があり、それを最後にまとめています。

## 設定

- G は木構造の因子グラフとします。変数と因子を頂点とし、「因子が変数を含む」を辺とした 2 部グラフが閉路を持たない、という意味です。
- クエリは、全変数 x について q_x = Σ_{x 以外の全変数} Π_{全因子} f です（`marginal_query`）。
- 書き換え規則は次のとおりです（`egfg/egraph.py`）。
  - (C) 積の交換律
  - (A) 積の結合律
  - (S) 和の交換：Σ_u Σ_w t = Σ_w Σ_u t
  - (D) 分配則：u ∉ scope(a) のとき Σ_u (a·b) = a·Σ_u b
- コストは、葉 0、積は結果のスコープの大きさ、和は子のスコープの大きさです。DAG の各ノードは 1 回だけ数えます。

## BP を項として書く

- 因子から変数へのメッセージ：m(f→x) = Σ_{scope(f)∖x} [ f · Π_{y ∈ scope(f)∖x} μ(y→f) ]
- 変数から因子へのメッセージ：μ(y→f) = Π_{g ∋ y, g ≠ f} m(g→y)（空の積なら省略）
- 周辺分布：B(x) = Π_{f ∋ x} m(f→x)

積の順序と和の順序は、名前順・ID 順に固定します（`factor_graph_bp_dag`）。これらの項をすべて共有して 1 つの DAG にしたもののコストを cost(BP) とします。

## 主張

飽和した e-graph には、各 q_x の e-class に B(x) が入っている。したがって、BP の DAG は抽出の候補の一つであり、最適な DAG 抽出のコストは cost(BP) 以下である。

## 補題 1（到達可能性）

**主張**：各変数 x について、q_x と B(x) は規則 (C)(A)(S)(D) で互いに書き換えられる。

**証明の考え方**：x を根として木をたどり、部分木の大きさについての帰納法で示します。

1. x に接する因子を f₁, …, f_k とします。木なので、f_i の先にある部分木 T_i どうしは、x 以外の変数を共有しません。
2. (C)(A) で、全因子の積を「T_1 の因子の積 × … × T_k の因子の積」に並べ替えます。
3. (S) で和の順序を並べ替え、T_i の変数（x を除く）の和を、まとめて置きます。
4. (D) を繰り返し適用し、T_i の変数の和を、T_i 以外の因子の積の外側から内側へ押し込みます。T_i の変数は他の部分木の因子に現れないので、(D) の条件 u ∉ scope(a) がいつも満たされます。**ここが「木であること」を使う唯一の場所です。**
5. すると q_x = Π_i [Σ_{T_i の変数} (T_i の因子の積)] になります。各括弧の中は、部分木 T_i を根 x から見たときの周辺化そのものです。
6. f_i のもう一方の変数 y についても同じ操作を行うと、括弧の中は m(f_i→x) の形になります（y から先の部分木が μ(y→f_i) になる）。部分木は真に小さいので、帰納法の仮定が使えます。

## 補題 2（共有）

**主張**：m(f→x) と μ(y→f) は、どのクエリ q_z の中に現れても同じ項であり、同じ e-class に入る。

**理由**：メッセージの項は (f, x) だけで決まり、どのクエリから来たかによりません。積と和の順序を固定しているからです。e-class の中には、規則で互いに書き換えられる並べ方がすべて同居します。そのため、どのクエリから到達しても、固定した順序の項が同じ e-class に含まれます。e-graph はハッシュコンシングされているので、同じ項は同じ e-node です。

## 結論

補題 1 から、各 q_x の e-class に B(x) が存在します。補題 2 から、そこで使われるメッセージの項は、すべてのクエリで同じ e-node を共有します。したがって、「各 e-class で BP の項に対応する e-node を選ぶ」という選び方は、正しい DAG 抽出になっており、そのコストはちょうど cost(BP) です。最適な抽出はこれ以下のコストを持ちます。□

なお、実験では星形のグラフで最適な抽出が BP より真に安くなりました。μ(y→f) の積を送り先ごとに作り直さず、部分積を共有する形が e-graph の中に存在するためです。主張は「≤」なので、矛盾しません。

## 残っている穴

1. **飽和が有限で終わること**：実験では毎回、有限回で飽和しました。証明するには、「各 e-class は、ある因子の部分集合 F' と、和をとる変数の集合 V' の組 (F', V') に対応し、そのような組は有限個である」という議論が必要です。ただし、等しい意味の項がすべて同じ e-class に統合されること（規則の完全性）は、まだ示していません。
2. **反復回数**：飽和を途中で打ち切った場合、補題 1 の書き換えが反復回数・ノード上限の内側に収まることは示していません。実際、変数 8 個の星形ではノード上限に達し、主張が成り立ちませんでした。
3. **補題 1 の手順 6 の細部**：(C)(A) で積を任意の木の形に組み替えられることと、μ が空の積の場合の扱いを、きちんと書く必要があります。
4. **ループのあるグラフ（H2）**：ジャンクションツリーへの一般化では、クリークの中の変数が他の部分木に現れないという条件を、セパレータを使って言い直す必要があります。
