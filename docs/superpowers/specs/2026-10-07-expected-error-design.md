# egfg 設計仕様（フェーズ I）：観測についての仮定による、近似の誤差の期待値の事前計算

- 日付：2026-10-07
- 状態：承認済み（2026-10-07）
- 前提：フェーズ H（`2026-10-07-approximation-design.md`）

## 1. 目的

フェーズ H では、混合をまとめる位置の選択を、粗い罰則 λ（まとめる成分の数 × まだ掛けていない観測の数）で行った。また、実行時の誤差の上界は 1〜4 ステップで自明になった。

そこで、「観測はモデルから生まれる」という仮定を置き、まとめる演算 1 回あたりの誤差の期待値の上界を、モデルのパラメータだけから計算する（シミュレーションは使わない）。これを抽出のコストに使い、λ を「誤差 1 nat あたりの演算回数」という意味のある値 μ に置き換える。

問い：

- H19（上界の正しさ）：事前に計算した値は、モデルから生成した観測で実際に測った「まとめの KL の上界」の平均を上回る（または近い）。
- H20（選択の質）：μ を変えて得た計算は、演算回数と実際の誤差のつりあいで、フェーズ H の λ による選択より良いか同じ。とくに、λ = 0 で選ばれた「安いが誤差の大きい置き方」（3 つの目標）を選ばない。

## 2. 上界の導き方

まとめる演算は、ある e-class の値（離散の変数の組 D_c と連続の変数 x_s を持つ）を、離散の変数 m' について和をとって、1 つのガウスにする。実行時の上界は、

  Σ_a W_a Σ_{m'} w_{m'|a} KL(N_{a,m'} ‖ q_a) = Σ_a W_a · ½ [log det P̄_a − Σ_{m'} w_{m'|a} log det P_{a,m'}]

である（a は残る離散の変数 D_o = D_c − {m'} の組。右辺は、まとめたガウスが平均と共分散を一致させたものであることから出る恒等式）。

まとめる前の値が厳密（モードの履歴について正しい混合）なら、P̄_a = Cov(x_s | D_o = a, データ)、P_{a,m'} = Cov(x_s | D_c = (a, m'), データ)、W と w は事後確率である。観測がモデルから生まれるとき、期待値は次で上から押さえられる。

- 第 1 項：E[P(a | Y) log det Cov(x_s | a, Y)] = P(a) E[log det Cov(x_s | a, Y) | a] ≤ P(a) log det C_lin(a)。
  - log det の凹性（イェンセン）と、「条件付き期待値の誤差 ≤ 線形推定の誤差」による。
  - C_lin(a)：D_o = a のもとでの (x_s, 観測) の 1 次・2 次のモーメントから作る、線形推定（LMMSE）の誤差の共分散。使う観測を直近 L ステップに限っても上界のまま（情報が少ないほど誤差は大きい）。
- 第 2 項：E[P(b | Y) log det Cov(x_s | b, Y)] ≥ P(b) E[log det K_σ | b]。
  - 全てのモードの列 σ を知れば、共分散はカルマンフィルタの共分散 K_σ になり、観測によらない。全分散の法則と log det の凹性により、Cov(x_s | b, Y) の log det は E[log det K_σ | b, Y] 以上。観測について平均すると E[log det K_σ | b]（塔の性質）。
  - K_σ は窓の始めの共分散を 0 として計算する（リカッチの単調性により下から押さえる）。

したがって、厳密な入力に対するまとめ 1 回の期待 KL は、

  ε ≤ Σ_a P(a) · ½ log det C_lin(a) − Σ_b P(b) · ½ E[log det K_σ | b]

で、モデルのパラメータだけから計算できる。

- モーメントは、モードの列（窓の L + 1 ステップ分）ごとに線形ガウスのモーメントを計算し、モードの列の事前確率で混ぜて求める。窓の始めの状態のモーメントは、マルコフジャンプ線形系の定常の 2 次モーメント（モードごとの E[x 1{θ=i}]、E[x xᵀ 1{θ=i}]）を使う。
- 途中のテンプレートは定常状態（窓の始めが定常）で、先頭のテンプレート（t = 0）は初期分布で計算する。
- 窓の長さ L は、モードの列の数（M^{L+1}）が数千以下になるように選ぶ。

## 3. 前提と限界

- 観測がモデルから生まれること（モデルが正しいこと）。
- 遷移が安定で、モードの連鎖が定常分布を持つこと（途中のテンプレートの定常の仮定）。
- 上界は、まとめる前の値が厳密なときのもの。実際のフィルタでは、前の時刻までの近似が入っているので、これは目安になる（H19 で確かめる）。
- 時間をまたいだ誤差の蓄積は扱わない（1 ステップあたりの、まとめの誤差の和だけ）。

## 4. 抽出での使い方

- まとめる実装のコストに μ × ε を足す（ε は上の上界、単位は nat）。ε は、まとめる値の形（D_c、m'、x_s の時刻、含まれる観測）ごとに一度だけ計算して使い回す。
- 局所の変数名（`m0@-1`、`x0@0` など）は、積み上げたモデル（モードの組、状態の積み上げ）の成分と時刻に対応させる。複数の観測の一部だけを含む値では、その時刻の観測をその行だけに限る。
- μ を変えて抽出し（たとえば 0、1、10、100、1000）、演算回数と ε の合計のつりあいの違う計算の集合を出す。フェーズ H の λ も残す（比較のため）。

## 5. 実験

- モデルはフェーズ H と同じ。
- 測るもの：
  - 各計算の ε の合計（事前）と、実行時のまとめの KL の上界の平均（モデルから生成した観測での測定。比較のためだけに使う）。
  - 演算回数と実際の誤差（数え上げた厳密な事後分布との差）。μ による選択と λ による選択の、つりあいの比較。
  - ε の計算の時間。
- 成果物：`results/expected_error.csv`、`experiments/EXPECTED_ERROR_REPORT.md`。

## 6. テスト

- 2 次モーメントの計算が、長い実行の平均（解析的な漸化式の収束先）と一致する。小さな例で、モードの列ごとのモーメントの混合が、数え上げた厳密な分布のモーメントと一致する。
- 1 次元の小さな例で、ε が、厳密な入力に対するまとめの KL の上界の期待値（全ての観測の列の上での数値積分。テストのためだけ）以上になる。
- μ = 0 では演算回数の最小、μ が十分大きいとき GPB2 の置き方が選ばれる。

## 7. 範囲外

- 時間をまたいだ蓄積の上界（混ざる速さによる縮み）。
- 枝刈り・硬い判断の誤差の期待値。
- 線形ガウスでない成分。
