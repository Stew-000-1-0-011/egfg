# egfg 設計仕様（フェーズ F）：消去順序では表せない規則 ― 因子の低ランク分解

- 日付：2026-10-06
- 状態：承認済み（2026-10-06、ユーザーの指示「消去順序では表せない規則を足して」による）
- 前提：フェーズ E（`2026-10-06-search-order-design.md`）

## 1. 目的

フェーズ E で、今の規則の範囲での e-graph の寄与は「既知の工夫（消去順序と途中結果の共有）の組み合わせ」だと分かった。e-graph ならではの効果を出すには、消去順序では表せない等式を足す必要がある。最初の例として、因子の表の低ランク分解を入れる。

因子の表 φ を、その変数を 2 つの組（左と右）に分けて行列とみたとき、ランクが r なら

  φ(左, 右) = Σ_z U(左, z) · V(z, 右)　（z は状態数 r の新しい変数）

と書ける。この等式を e-graph に入れると、新しい変数 z を挟んだ計算が選べるようになる。たとえば、状態数 K の鎖で遷移の表のランクが r なら、メッセージの計算は 2K² から約 4Kr になる。元の変数の消去順序だけでは、この計算は表せない。

問い：

- H14：表に低ランクの構造があるとき、e-graph は分解を使って、元のグラフの最良の計算（best-JT+、木なら BP）より安い計算を見つける。
- H15：分解を使うと損になる因子（ランクが十分に小さくない、またはつながり方が悪い）では、e-graph は分解を使わない計算を選ぶ。そのため、「分解できる因子をすべて分解したグラフ」に対する最良のジャンクションツリーよりも安いか、同じになる。

## 2. 等式の作り方

- 2 変数以上の各因子について、変数の分け方（左と右、どちらも空でない）ごとに、表を行列にして特異値分解する。相対的な許容誤差 1e-9 より大きい特異値の数をランク r とする。
- r < min(左の状態数の積, 右の状態数の積) のときだけ、分解を作る（得をする可能性があるとき）。
  - 新しい変数 z（状態数 r）と、新しい因子 U（左 ＋ z）、V（z ＋ 右）を作る。
  - 表は特異値分解から作る（U = 左特異ベクトル × 特異値、V = 右特異ベクトル）。値は負になりうる。
  - 等式「Leaf(φ) = Σ_z (Leaf(U) · Leaf(V))」を e-graph に union する。
- 分解は複数作ってよい（分け方ごと、因子ごと）。どれを使うか、使わないかは抽出が選ぶ。
- 新しい変数と因子を加えた因子グラフ（拡張したグラフ）で、スコープの解析・コスト・評価を行う。クエリは元の変数だけ。

## 3. 使える範囲

- 分解は Σ_z（和）を使うので、和と積の評価（周辺分布）でだけ正しい。最頻値（max-product）と期待値半環では成り立たないので、分解を使った計算でそれらを求めようとしたらエラーにする。
- 表の値が負になりうるので、拡張したグラフに限って負の値を許す（`FactorGraph(..., allow_negative=True)`）。
- 分割（cluster_budget）とは組み合わせない（分割ありで分解を指定したらエラー）。
- 種：元のグラフの複数の消去順序のジャンクションツリーに加えて、「分解できる因子を最もランクの低い分け方で分解したグラフ」のジャンクションツリーも種にする（その項は元のクエリと値が等しい）。

## 4. 公開 API

- `optimize(fg, ..., structure=("lowrank",))`。既定は `()`（今までどおり）。
- `OptimizeResult` に、評価に使う拡張したグラフと、和と積でしか使えないかどうかを持たせる。

## 5. 実験

- 問題：鎖、星形、ランダムな木、輪、2×3 の格子（n = 6〜8）。2 変数因子の表を、非負の乱数行列の積（ランク r）で作る。K ∈ {8, 16}、r ∈ {1, 2, 4, K}（K は分解できない場合）。
- 比べるもの：分解なしの既定（seeds+staged）、分解ありの既定、元のグラフの best-JT+、分解したグラフの best-JT+、木なら BP。
- 正しさ：総当たりの周辺分布と一致すること。
- 成果物：`results/low_rank.csv`、`experiments/LOW_RANK_REPORT.md`。

## 6. テスト

- 分解の等式が数値的に正しい（Σ_z U·V が元の表と一致）。
- 分解ありの周辺分布が総当たりと一致する（いくつかの種類とランク）。
- 低ランクの表で、分解ありのコストが分解なしより小さい。フルランクの表では分解は作られない。
- 分解ありで最頻値・期待値を求めるとエラーになる。分割と組み合わせるとエラーになる。
- 既定（分解なし）の結果は変わらない。
