# egfg フェーズ D 実装計画：線形ガウスモデルと、表現を考慮した抽出

**Goal:** 線形ガウスの動的モデルのフィルタリングで、計算の形は e-graph で、中間結果の表現（モーメント形式・情報形式・条件付き形式）は抽出で選ぶ。

**Spec:** `docs/superpowers/specs/2026-10-06-gaussian-design.md`

## Global Constraints

- 離散の場合のコード（フェーズ 1〜C）の動作と結果は変えない。既存のテストは変更しない。
- e-graph の飽和は既存の `saturate` をそのまま使う（構造だけを渡す）。

## 仕様で決めきれていなかった点の扱い

1. **構造だけの因子グラフ**：飽和には、各変数の状態数を 1、表を大きさ 1 にした `FactorGraph` と、フェーズ B の `DynamicModel`／`local_step` をそのまま使う（クエリ・種・入力の葉・観測の因子の番号を流用）。数値と次元は D 側で持つ。
2. **予測（モーメント × 条件付き分布）のコスト**：仕様の表の式は、モーメント側に親以外の変数があるときの交差共分散の分を落としていた。実装では d_子 d_親 d_S ＋ d_子² d_親（d_S はモーメント側の次元の合計）とする。親以外の変数がなければ仕様の式と一致する。
3. **事前分布の葉**：事前分布はそのままモーメント形式で持てる（コスト 0）。
4. **メッセージの表現**：前向きのメッセージの表現 r（モーメントか情報）を、r ごとに先頭と途中のテンプレートを抽出して、途中の 1 ステップのコストが小さいほう（同じなら先頭も含めて小さいほう）を選ぶ。
5. **周辺分布の根**：答えの取り出しにモーメント形式が要るので、周辺分布の根は (e-class, モーメント) に固定する（変換が要るなら、そのコストは抽出の中で数える）。
6. **カルマンフィルタ・情報フィルタの比較の相手**：状態全体を 1 本のベクトル変数にまとめた（積み上げた）モデルを作り、表現をモーメント形式だけ／情報形式だけに限って同じ抽出を使う。積み上げたモデルでは計算の形に選ぶ余地がないので、それぞれ標準のカルマンフィルタ・情報フィルタに当たる。
7. **スコープが重ならないモーメント形式どうしの積**：仕様の演算の表になかったが、独立な事前分布をまとめるのに必要（モーメント形式だけのカルマンフィルタで、ブロックごとの事前分布から同時分布を作る）。ブロック対角に並べるだけなので、モーメント形式の積分と同じくコスト 0 とする。
8. **パラメータだけで決まる計算（オプション `amortize_constants`）**：仕様の表では、条件付き形式 → 情報形式の変換を毎ステップ数える。しかし遷移の情報形式や観測の HᵀR⁻¹H はモデルのパラメータだけで決まり、実際の情報フィルタは一度だけ計算する。既定は仕様どおりとし、オプションで「毎ステップ数えるのは観測に依存する h = HᵀR⁻¹(y − b) の計算（m × d）だけ」にできるようにする。実験では両方を記録する。
9. **正しさの参照**：積み上げたモデルに対する標準のカルマンフィルタを numpy で直接書く（egfg の評価器を使わない）。

## File Structure

- `src/egfg/gaussian.py`：線形ガウスの因子、値（情報形式・モーメント形式）と演算、コストの式、積み上げ、参照のカルマンフィルタ、生成器。
- `src/egfg/repextract.py`：表現を考慮した抽出（木・貪欲 DAG・ILP）。表現と演算は呼び出し側が与える一般的な形にする。
- `src/egfg/gdynamic.py`：線形ガウスの動的モデル、テンプレートの探索、フィルタリング、比較の相手。
- `experiments/gaussian.py`、`experiments/GAUSSIAN_REPORT.md`、`results/gaussian.csv`。
- `tests/test_gaussian.py`、`tests/test_gaussian_experiment.py`。

## Tasks

1. 値と演算（テスト：積・積分・変換が密な行列の直接計算と一致）。
2. 表現を考慮した抽出（テスト：表現が 1 つなら従来の抽出と同じ選択とコスト、ILP ≤ 貪欲 ≤ 木、循環なし）。
3. 正規化の判定と、線形ガウスのテンプレート・フィルタリング（テスト：参照のカルマンフィルタと一致、T = 1）。
4. 比較の相手と仕様 8 章の残りのテスト（表現を限ったときのコスト、両方使えるときのコスト ≤ 片方だけ）。
5. 実験とレポート。
