# egfg フェーズ I 実装計画：近似の誤差の期待値の事前計算

**Goal:** 観測がモデルから生まれるという仮定のもとで、まとめる演算 1 回あたりの期待 KL の上界をモデルのパラメータだけから計算し、抽出のコストに使う。

**Spec:** `docs/superpowers/specs/2026-10-07-expected-error-design.md`

## 仕様で決めきれていなかった点の扱い

1. **窓の観測**：窓の始めの時刻の観測も使う（使う観測が多いほど上界は小さくなり、上界であることは変わらない）。いまの時刻 t の観測は、まとめる値に含まれる観測因子の行だけ。それより前の時刻は全ての行（メッセージが過去の観測をすべて含むため）。
2. **下界のカルマン共分散**：窓の始めの状態を既知（共分散 0）として、モードの列と観測を与えたときの x_s の条件付き共分散（線形ガウスのシューア補行列）を使う。x_s が 1 つ前の時刻（平滑化）でも同じ式で下界になる。先頭のテンプレート（t = 0）では、事前分布が厳密に分かっているので、その共分散を使う（下界ではなく厳密）。
3. **窓の長さ**：L = min(6, ⌊log 4096 / log M⌋ − 1)（M は積み上げたモデルのモードの組の数）。
4. **局所の変数の対応**：`name@τ` を、積み上げたモデルのモードの組の成分（離散）または状態のブロック（連続）と、時刻 t + τ に対応させる。
5. **キャッシュ**：上界は（D_c、まとめる変数、連続の変数、含まれる観測の行、先頭か途中か）ごとに一度だけ計算する。

## File Structure

- `src/egfg/switching_bound.py`：定常の 2 次モーメント、窓の中のモードの列ごとのモーメント、上界の計算。
- `src/egfg/switching.py`：`price`（μ）を受け取り、まとめる実装のコストに μ × ε を足す。
- `experiments/expected_error.py`、`experiments/EXPECTED_ERROR_REPORT.md`、`results/expected_error.csv`。
- `tests/test_switching_bound.py`。
